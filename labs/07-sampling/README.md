Open a selected model in MATLAB/Simulink, inspect its blocks and parameters, then run the simulation and examine the scopes. All original model variants were retained; no single version has been designated as canonical. Models labeled `2024a` may have release-specific requirements. Block dependencies and compatibility have not been verified by running Simulink.
