# Z-transform and recursive systems

[Back to repository](../../README.md) · [Course guide](../../materials/lab-guides/z-transform.pdf)

[Transformada_z.m](Transformada_z.m) explores partial-fraction expansion with `residuez`, an analytical step response, a difference-equation implementation, and comparisons with `stepz` and `impz`. It also plots a second-order filter's frequency response.

Set MATLAB Current Folder to this directory and run `Transformada_z`. Requirements: MATLAB and Signal Processing Toolbox. No external data files are loaded; coefficients and test sequences are defined in the script.
